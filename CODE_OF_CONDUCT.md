# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. The short form:

- Be respectful. Disagree with ideas, not people. Assume good faith.
- No harassment, personal attacks, or discriminatory language, in issues, pull
  requests, discussions, commit messages or anywhere else connected to the project.
- Keep technical criticism specific and about the work. "This benchmark has no
  recall column" is useful; "this is garbage" is not.
- Respect people's time: search before filing, include what the templates ask for,
  and accept that a maintainer's "no" or "not now" is an answer.

Report a problem by opening an issue if it can be public, or by contacting the
maintainer through the address on their [GitHub profile](https://github.com/jatinsethi98)
if it cannot. Reports are handled privately, and the maintainer may warn, restrict or
ban a participant depending on the severity and the pattern.

The full text of the Covenant, including the enforcement guidelines, applies where
this summary is silent.
